# Contributing to Solana Alpha Scout

Thank you for your interest in contributing to **Solana Alpha Scout**!

## How to Contribute

1. **Fork the Repository**
2. **Create a Feature Branch**
   ```bash
   git checkout -b feature/amazing-feature
   ```
3. **Commit Your Changes**
   ```bash
   git commit -m "feat: add amazing feature"
   ```
4. **Push to Your Branch**
   ```bash
   git push origin feature/amazing-feature
   ```
5. **Open a Pull Request**

## Development Guidelines

- **Code Quality:** Ensure all Python and Rust Anchor code passes linting and unit tests.
- **Commit Messages:** Follow the Conventional Commits specification (`feat:`, `fix:`, `docs:`, `style:`, `refactor:`).
- **Security:** Never commit private keys, `.env` files, or sensitive RPC endpoints.
